# TMLR Profile

Use this profile when the venue is TMLR or unspecified, then refresh official TMLR pages for the live run.

## Official Labels

Reviewer recommendation context:

- `accept`;
- `leaning accept`;
- `leaning reject`;
- `reject`.

AE decision context:

- `accept as is`;
- `accept with minor revisions`;
- `reject`.

Use these labels only at report or summary level. Issue-level labels remain internal.

## Criteria To Check

Review whether claims are supported by accurate, convincing, and clear evidence; whether the findings interest the TMLR audience; which requested changes are critical for acceptance; reproducibility; clarity; submission format; ethics and broader-impact concerns.

Do not invent TMLR numerical scores or treat internal issue labels as official TMLR fields.
