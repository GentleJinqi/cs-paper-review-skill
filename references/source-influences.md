# Source Influences

This protocol is an original synthesis of mechanisms developed through repeated CS paper review runs. It does not vendor, copy, or runtime-download external skill repositories.

## Preserved Mechanisms

PaperJury-style mechanisms:

- independent reviewer isolation;
- evidence-anchored issue ledgers;
- adversarial adjudication;
- no silent dropping of supported issues;
- author-data gates;
- explicit subagent cleanup records.

Academic Research Skills-style mechanisms:

- reviewer simulation;
- editorial decision synthesis;
- research-integrity checks;
- revision triage;
- source-verification discipline.

Research Paper Writing-style mechanisms:

- claim-evidence mapping;
- section-flow review;
- experiment-support checks;
- reviewer-facing clarity checks;
- writing and AI-surface audits.

## Release Rule

When publishing this skill, cite upstream repositories only as inspiration. Do not copy their files or require users to install them.
