# Venue Refresh

Create a venue profile before dispatching reviewers.

## Source Priority

1. Official venue pages: reviewer guide, author guide, submission instructions, ethics policy, reproducibility checklist, AE or PC guide, formatting instructions, and FAQ pages.
2. Official review forms or OpenReview venue pages when they are part of the venue's official submission system.
3. Non-official materials only when official sources are missing or insufficient.

Official sources control the rubric. Non-official sources may calibrate field norms only when labeled as non-official.

## Required Output

Write `official-rubric.md` with:

- venue name and retrieval date;
- official URLs used;
- what each source contributes;
- reviewer recommendation or score fields only when official;
- decision labels only when official;
- submission, ethics, reproducibility, and formatting criteria;
- fallback rationale when official material is unavailable.

Do not start the main review until `official-rubric.md` exists or the contract records why official sources were unavailable.
