# Changelog

## 0.2.1 — 2026-07-28

- Added a concise, user-facing conceptual pipeline to both English and Chinese
  READMEs so readers can see the normal per-paper review flow, evidence-driven
  delegation loop, completion gate, and delta-review loop at a glance.
- Kept maintainer-only skill-update and release orchestration out of the public
  README.

This is a documentation-only patch. It does not change the portable scientific
core, venue profiles, Sol Ultra adapter, schemas, validators, lifecycle
selection, or evaluation claims from `0.2.0`.

## 0.2.0 — 2026-07-28

- Rebuilt the public repository as the portable review-core authority while
  keeping project-specific manuscript facts and review history local.
- Added a venue-neutral scientific core, canonical coverage and finding
  contracts, source/PDF verification, delta lineage, dissent preservation,
  truthful partial/blocked states, and deterministic human bindings.
- Added source-bounded TMLR, ICML 2026, CVPR 2026, and ECCV 2026 overlays.
- Added a Codex GPT-5.6 Sol Ultra adapter with one root scheduler,
  quality-driven optional delegation, leaf-only substantive children, and no
  fixed reviewer or agent count.
- Added oracle-blind lifecycle comparison artifacts and selected the
  disk-backed `persisted-task-registry` after a two-to-one strict-preference
  majority over the six declared semantic dimensions.
- Added a 16-fixture public conformance suite with an immutable 15/16 base
  result, a narrowly scoped venue-profile correction, and a final independent
  16/16 semantic adjudication covering all 10 required obligations.
- Added privacy-safe closure records while keeping project-manuscript review,
  manuscript revision, and experiment execution outside this release scope.
- Refreshed the three existing external references and screened additional
  mechanisms without copying external pipelines or style prompts.

This release does not claim host-effective runtime attestation, acceptance
probability, or universal semantic proof.
