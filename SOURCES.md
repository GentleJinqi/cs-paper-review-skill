# Sources and Adoption Boundary

Exact repositories, commits, licences, and dispositions are recorded in
`sources/source-lock.json`. Mechanism-level decisions and overlap are recorded
in `sources/adoption-matrix.md`.

The core independently implements only mechanisms that close a demonstrated
review-quality gap: frozen input and source/PDF integrity, evidence-anchored
finding falsification, canonical adjudication and closure, dissent
preservation, stable delta identity, and hash-bound evaluation records. It
does not copy external prompts, personas, fixed fan-out, model tiers, output
style, or repository layout.

The three pre-existing local references were current at the 2026-07-28 audit.
New candidates remain evaluation-only unless an incremental, oracle-bounded
test demonstrates additional supported finding quality without regression.
