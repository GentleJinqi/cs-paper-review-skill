# Migration from the 2026-06-23 workflow

The initial repository is historical provenance, not the active runtime
contract.

- Do not default an unspecified target to TMLR. Keep it venue-neutral.
- Do not dispatch a fixed reviewer roster. Start with one root and delegate
  only for a distinct material evidence need.
- Do not use vote, reviewer, or agent count as scientific confidence.
- Use the canonical criterion coverage and finding ledger rather than parallel
  prose issue stores.
- Treat source content and rendered PDF evidence separately.
- For a delta review, bind a validated predecessor, typed author response,
  visible prior/current revision evidence, and stable finding identities.
- Treat venue fields as an additive, source-bounded overlay. They never replace
  scientific correctness or become acceptance probability.

Project-specific review history, manuscript paths, author gates, and local
protocol decisions stay in the consuming project. The public repository is
the portable release authority only.
